# Customization

## Colours

| Role | Light | Dark |
| --- | --- | --- |
| Background | `F8FAFC` | `0B1F3A` |
| Text | `334155` | `E2E8F0` |
| Accent | `0FB5BA` | `2DD4BF` |

The widget URLs in `README.md` carry these values as query parameters. Change them in both the light and dark variants.

## Technology icons

Edit the `i=` list in the Skill Icons URL (comma separated). Available names are listed at <https://skillicons.dev>. Only show tools you actually use.

## Featured projects

Add a row to the table only after you have opened the repository and confirmed what it does. Use its real README and source code for the description and stack.

## Certifications

Update both the compact table in `README.md` and the matching section in `certifications/README.md`. Never alter names, dates or IDs shown on a certificate.
